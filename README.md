## Overview

InterviewAI simulates a real verbal interview experience. The AI interviewer asks 10 structured questions (technical, behavioral, and vision-based), listens to your spoken answers, evaluates them strictly using a scoring rubric, and generates a comprehensive performance report at the end.

---

## ✨ Features

- 🎙 **Voice-Powered** — Answer by speaking; real-time transcription via Groq Whisper
- 🤖 **AI Interviewer** — Questions generated by LLaMA 3.1 (via Groq API), tailored to your job title & level
- 🔊 **Text-to-Speech** — Questions are read aloud using Microsoft Edge TTS (Aria Neural voice)
- 📊 **Strict Scoring** — Answers graded 0–10 with a detailed rubric; off-topic answers penalized
- 📝 **Detailed Report** — Per-question scores, strengths, weaknesses, and an overall hiring recommendation
- 🌍 **Universal** — Works for any job title (Developer, Manager, Doctor, Teacher, etc.)
- 🎨 **Premium UI** — Dark glassmorphism design with smooth animations


## 🔄 How It Works

### User Flow

```
1. Home Page
   → Enter Job Title (e.g. "React Developer", "Marketing Manager")
   → Select Experience Level (Junior / Mid-level / Senior / Lead)
   → Click "Start Interview"

2. Interview Page
   → AI generates 10 tailored questions using LLaMA 3.1
   → Questions are read aloud via Microsoft Edge TTS (Aria Neural voice)
   → User speaks their answer — audio is recorded
   → On submit: audio is transcribed by Groq Whisper
   → Answer is evaluated and scored (0–10)
   → Next question is loaded automatically
   → Repeat for all 10 questions

3. Result Page
   → Overall score ring with color-coded rating
   → AI-written performance summary
   → Per-question breakdown: score, feedback, strengths, weaknesses
   → Hiring recommendation: Reject / Consider / Hire
```

### Scoring System

| Score | Meaning |
|---|---|
| 9–10 | Excellent — precise, deep conceptual knowledge |
| 7–8 | Strong — accurate with minor gaps |
| 5–6 | Adequate — partial understanding |
| 3–4 | Weak — vague or off-topic |
| 1–2 | Poor — mostly irrelevant |
| 0 | No answer / completely wrong |

> **Strict rules:** Off-topic answers are penalized 4–5 points. Vague filler answers lose 3 points. "I don't know" type answers max out at 4.

### Question Structure (per interview)

| Questions | Type |
|---|---|
| Q1–Q5 | Technical conceptual (role-specific) |
| Q6–Q8 | Behavioral / situational |
| Q9–Q10 | Career vision / industry insight |

## 🌐 API Reference

Base URL: `http://localhost:8000/api`

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/start-interview` | Create session, return welcome audio |
| `POST` | `/generate-questions/{session_id}` | Generate 10 questions via LLM |
| `GET` | `/get-first-question/{session_id}` | Get Q1 text + audio |
| `POST` | `/submit-answer` | Submit audio → transcribe → evaluate → next Q |
| `POST` | `/end-interview/{session_id}` | End early, generate partial report |
| `GET` | `/evaluation/{session_id}` | Fetch the final report |

### `/start-interview` Request Body
```json
{
  "job_title": "React Developer",
  "experience_level": "Mid-level"
}
```

### `/submit-answer` Request (multipart/form-data)
```
session_id: <string>
audio: <audio file (.webm)>
```

## 🔧 Configuration

### Changing the AI Voice

In `backend/services/audio.py` line 38, change the voice name:

```python
communicate = edge_tts.Communicate(text, "en-US-AriaNeural")
```

Popular alternatives:
| Voice | Description |
|---|---|
| `en-US-AriaNeural` | Female, warm (default) |
| `en-US-GuyNeural` | Male, professional |
| `en-US-JennyNeural` | Female, conversational |
| `en-GB-SoniaNeural` | British female |
| `en-US-DavisNeural` | Male, casual |

### Changing the LLM Model

In `backend/services/llm.py`:

```python
model_name="llama-3.1-8b-instant"   # current (fast, free)
# alternatives:
# model_name="llama-3.3-70b-versatile"  # more powerful
# model_name="mixtral-8x7b-32768"       # alternative
```

### Changing Number of Questions

In `backend/graph/prompts.py`, change "10" to your desired count and update `nodes.py` accordingly.

## 🎨 Customization

### UI Colors & Theme
All design tokens are in `frontend/src/index.css` under `:root {}`. Edit CSS variables to change colors, fonts, shadows, etc.

### Interview Question Types
Edit `QUESTION_GENERATION_PROMPT` in `backend/graph/prompts.py` to modify the question structure and rules.

### Scoring Strictness
Edit `EVALUATION_PROMPT` in `backend/graph/prompts.py` to adjust the rubric and deduction rules.

## 🔑 Getting a Groq API Key

1. Go to [https://console.groq.com/](https://console.groq.com/)
2. Sign up for a free account
3. Navigate to **API Keys** section
4. Create a new key and copy it
5. Paste it in `backend/.env` as `GROQ_API_KEY=your_key_here`

> Groq offers a **free tier** with generous rate limits — sufficient for development and testing.

## 📝 Notes

- **Session storage is in-memory** — sessions are lost when the backend restarts. For production, replace `core/state_store.py` with a database (Redis, PostgreSQL, etc.)
- **Browser permissions** — The app requires microphone access. Allow it when prompted.
- **Internet required** — Groq API and Edge TTS both require an internet connection.
- **Windows users** — The project is fully tested on Windows. Edge TTS works natively.
